# Aldéria : la Couronne d'Aube

Un jeu de rôle fantasy au tour par tour, en 3D, pour **téléphone Android**. Chapitres 1 à 10 jouables. Une fois installé, le jeu fonctionne **sans connexion**.

## Télécharger

**[⬇ Télécharger Alderia.apk](https://github.com/sleepundleave-gif/alderia/releases/latest/download/Alderia.apk)** — application 1.4.1, jeu version 15 (20,8 Mo)

Page de téléchargement à partager : https://sleepundleave-gif.github.io/alderia/

1. Touchez le lien ci-dessus depuis le téléphone : le fichier `Alderia.apk` se télécharge.
2. Ouvrez-le. Android demande d'autoriser l'installation « depuis cette source » : acceptez. Si « Play Protect » affiche un avertissement, choisissez « Installer quand même ».
3. Lancez **Aldéria**.

Il faut Android 5 ou plus récent. Si une ancienne version d'Aldéria est déjà installée, installez celle-ci par-dessus : **les sauvegardes sont conservées**.

## Mises à jour

À chaque lancement, si le téléphone est connecté, le jeu regarde ici s'il existe une version plus récente et l'annonce à l'écran titre (« ★ Nouvelle version »). Rien ne se télécharge sans votre accord : touchez **Mises à jour → Chercher en ligne** pour l'installer. Les nouveaux chapitres s'ajoutent au jeu déjà installé.

Les toutes premières applications (1.0, 1.1 et 1.2) ne savent pas regarder en ligne toutes seules : installez une fois la version ci-dessus, et les suivantes s'annonceront d'elles-mêmes.

## Sur ordinateur

Dans les [téléchargements de la dernière version](https://github.com/sleepundleave-gif/alderia/releases/latest), le fichier `Alderia-hors-ligne.html` contient tout le jeu : ouvrez-le dans Chrome, Edge ou Firefox.

## Ce que contient ce dépôt

| Dossier | Contenu |
|---|---|
| `jeu/` | le jeu (pages, code, modèles 3D, outils). Mode d'emploi : `jeu/LISEZ-MOI.md` |
| `android/` | les sources de l'application Android et le script qui fabrique l'APK |
| `docs/` | le site : page de téléchargement et dossier `maj/` que l'application interroge pour les mises à jour |
| `LISEZ-MOI-Android.md` | installer, régler les graphismes, publier une nouvelle version |
